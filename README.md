# Последняя ночь года

Криминальная драма / нуар-триллер — визуальная новелла с RPG-элементами.
Пролог: 10 сюжетных блоков, 8 концовок, инвентарь, проверки навыков и бой на кубах.

**Запуск:** открыть `index.html` в браузере. Сборка и сервер не нужны.
(Шрифты грузятся с Google Fonts; без сети подставятся системные.)

## Сюжет

31 декабря, 23:07. Портовый город Порт-Ветров. Бывшему оперу Яну Корсаку звонит
младший брат Мика: он украл у банды БНК «ключ» — флешку с их чёрной бухгалтерией.
«Ищи меня там, где отец учил нас считать. До полуночи».
У тебя 53 минуты. Каждый выбор, разговор и драка стоят времени.

## Управление

| Действие | Клавиша |
|---|---|
| Дальше | клик / Пробел / Enter |
| Выбор варианта | 1–9 или клик |
| Кейс (инвентарь и досье) | I |
| Доска улик | B |
| Журнал | L или колесо вверх |
| Авто / Пропуск | A / S |
| Спрятать интерфейс | H или правый клик |
| Звук | M |
| Меню и сохранения | Esc |
| В бою: переброс / предмет / удар | R / E / Пробел |

## Механики

- **Предыстория** (опер / боксёр / карманник) задаёт статы СИЛА, ЛОВКОСТЬ, НЕРВЫ,
  здоровье, стартовый предмет и бонус в бою. От неё зависят доступные реплики и пути.
- **Время.** Часы в HUD идут к полуночи. Опоздал — получаешь концовку «Опоздал».
- **Проверки.** 2к6 + стат ≥ сложность. Шанс показан прямо на варианте выбора.
  1-1 — всегда провал, 6-6 — всегда успех. Провал можно перебросить, отпив из фляжки.
- **Закрытые варианты** видны, но зачёркнуты («нужно: Отмычки»): у мира больше дорог, чем у твоего билда.
- **Таймер.** Некоторые выборы горят — если не успеешь решить, решат за тебя.
- **Инвентарь.** Оружие даёт пассивные бонусы, еду и сигареты можно дарить и менять, ключевые предметы открывают ветки.
- **Доска улик.** Полароиды 10 блоков, красная нить по пройденному пути, найденные улики и открытые концовки
  (концовки сохраняются между прохождениями).
- **Сохранения.** Автосейв перед каждым выбором плюс 3 слота.

### Бой «Кости на сукне»

1. Противник открыто бросает кубы — это его **намерение** (урон, блок или подготовка к сильному удару).
2. Ты бросаешь 3–4 куба и раскладываешь их кликом или перетаскиванием:
   - **УДАР** — сумма + бонус силы и оружия;
   - **БЛОК** — гасит входящий урон; шестёрка даёт **КОНТРУ** (3 урона);
   - **ВЫСТРЕЛ** — один куб × 2 сквозь любую защиту (нужен револьвер и патрон); шестёрка — **В ЯБЛОЧКО** (15).
3. Комбинации в УДАРЕ: **ДУПЛЕТ** (+3), **ДВЕ ПАРЫ** (+6), **СТРИТ** (+5), **ТРОЙКА** (×2).
4. **Скрытый куб.** Один куб каждой атаки противника лежит рубашкой вверх — видно только «8 +?»,
   а прогноз показывает диапазон урона («получишь 8–14»). Куб вскрывается в момент удара.
   Предмет с флагом `reveal: true` вскрывает скрытые кубы заранее (появится в следующем акте).
5. Кубы, оставшиеся в лотке, можно перебросить. Один предмет за раунд.
6. Противники накладывают эффекты: кровотечение, ожог, наручники (−1 куб).
   Проигрыш не всегда смерть — часто это просто другая ветка.

### Баланс

Сложность врагов привязана к уровню опасности в досье и откалибрована симулятором
(`node tools/balance.js`): бот с полным ХП и одной аптечкой проигрывает

| Опасность | Враг | ХП | Поражений бота | Бот теряет ХП |
|---|---|---|---|---|
| 1 | Жаба | 46 | ~1% | ~10 |
| 2 | Шеф | 66 | ~15% | ~18 |
| 3 | Грох | 70 | ~30% | ~21 |
| 4 | Гусь | 65 | ~45% | ~21 |
| 5 | Бугай | 93 | ~60% | ~25 |

Предыстории выровнены: разница между ними в боях — не больше ~10 процентных пунктов.
После любой правки врагов, предметов или предысторий — перезапустить симулятор.

Планы: у отдельных врагов — свои приёмы и пассивки (например, «укол из блока»,
дебаффы в начале боя по условию), чтобы стиль боя у каждого ощущался уникальным.

## Структура кода

```
index.html              сцена 1920×1080 (масштабируется под окно) и порядок скриптов
assets/sprites/         спрайты персонажей
css/
  base.css              токены, сцена, постобработка (зерно, сканлайны, виньетка)
  stage.css             спрайты, досье, переходы, карточка главы
  dialogue.css          окно диалога, табличка имени, эффекты текста, выборы
  ui.css                HUD, тосты, модалки, кейс, доска улик, сохранения
  screens.css           титульный экран, создание персонажа, концовка, проверки, 3D-кубики
  combat.css            бой
js/
  core/                 namespace + утилиты + шина событий + ввод, состояние/сохранения, синтез звука
  data/                 персонажи, предметы (с SVG-иконками), враги, улики/концовки/предыстории, локации
  render/               процедурные фоны (canvas), спрайты, переходы, печатная машинка
  ui/                   диалог, выборы, HUD, кейс, доска, сохранения, полноэкранные экраны
  systems/              3D-кубики, проверки навыков, бой
  engine/story.js       реестр сцен и компилятор DSL → плоский список с метками
  engine/runner.js      интерпретатор сценария
  story/                сценарий: prologue.js (10 блоков), endings.js (концовки)
  main.js               инициализация и клавиатура
tools/balance.js        симулятор баланса боёв (node)
```

Модули — обычные скрипты, регистрирующиеся в `window.VN`, поэтому игра работает с `file://`.
Звук полностью синтезируется WebAudio, фоны рисуются на canvas — внешних медиафайлов, кроме спрайтов, нет.

## Сценарный DSL

Сцена — массив команд. Вложенные ветки компилируются в плоский список, поэтому
сохранение возможно в любой точке.

```js
VN.Story.scene('street', {
  title: 'Улица Канальная', block: 2, loc: 'street', board: { x: 270, y: 380 },
  script: [
    { bg: 'street', trans: 'blinds' },          // фон + переход: fade|blinds|ink|flash|glitch
    { place: 'Улица Канальная' },               // штамп локации со временем
    { n: 'Текст рассказчика {i}курсивом{/i}.' }, // n — рассказчик
    { show: 'kir', at: 'center', enter: 'silhouette' }, // drop|slide|glitch|fade
    { kir: 'Реплика. {shake}Дрожь{/shake} {pause=300}{red}красным{/red}' },
    { mika: '…', as: 'НЕИЗВЕСТНЫЙ НОМЕР' },     // подменить имя
    { give: 'cigs' }, { take: ['bullet', 1] }, { heal: 4 }, { hurt: 3 }, { sethp: 6 },
    { time: 5 }, { set: { flag: true } }, { sfx: 'phone', fx: 'shake' },
    { if: (S) => VN.State.flag('x'), then: [ … ], else: [ … ] },
    { label: 'ask' }, { jump: 'ask' }, { goto: 'police' },
    { choice: [
        { text: 'Вариант', time: 6, do: [ … ] },
        { text: 'Проверка', check: { stat: 'nrv', dc: 8 }, pass: [ … ], fail: [ … ], once: true },
        { text: 'Нужен предмет', need: 'badge', do: [ … ] },
        { text: 'Скрытый, пока не выполнено условие', if: () => …, do: [ … ] },
      ], timer: 9000, timeout: [ … ] },          // выбор на время
    { check: { stat: 'agi', dc: 9, label: '…' }, pass: [ … ], fail: [ … ] },
    { combat: 'frog', flee: true, opts: () => ({ enemyHp: 0.5 }), win: [ … ], lose: [ … ], fled: [ … ] },
    { trade: { prompt: '…', filter: (it) => it.food, do: [ … ], cancel: [ … ] } },
    { creation: true }, { loadout: { count: 2, options: [ … ] } },
    { ending: 'brother' },
  ],
});
```

Разметка текста: `{shake}`, `{wave}`, `{glitch}`, `{red}`, `{green}`, `{violet}`, `{ice}`, `{amber}`,
`{i}`, `{b}`, `{big}`, `{whisper}`, `{pause=мс}`, `{speed=k}`.
